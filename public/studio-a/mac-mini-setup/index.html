Mac mini・MacBook・iPhone
三機同步設定指南

不需要 GitHub、不需要架伺服器 — 只用 iCloud。
講師：余文皓 · mail@yu-wenhao.com｜2026-07

照這份指南做完，三台裝置會共用同一個工作資料夾：在任何一台的改動，另外兩台自動看到；兩台 Mac 都能用 Claude Code 直接在裡面工作。全程約 60 分鐘。

開始之前

整體架構：檔案只有一份

三台裝置不是互相傳檔案，而是看同一份。工作資料夾住在 iCloud 雲碟上，三台裝置登入同一個 Apple 帳號，同步自動發生，平常不需要做任何事。

第 1 章

Mac mini 開箱設定在 Mac mini 做

開箱依畫面指示完成初始設定，過程中登入你的 Apple 帳號。完成後做三件事，讓它適合當一台「不關機的常駐機」：

  1. 不讓它睡著 — 系統設定 → 能源：開啟「當顯示器關閉時，防止自動進入睡眠」和「斷電後自動啟動」。找不到的話，在系統設定左上角的搜尋欄輸入「能源」。
    為什麼：Mac mini 睡著就停止同步。螢幕可以關、機器不要睡 — 整天不關機的耗電比一顆 LED 燈泡還低。
  2. 自動登入 + 螢幕鎖 — 系統設定 → 使用者與群組：把「自動登入」設為你的帳號。停電或重開機後，它自己回到工作狀態，不用接鍵盤操作。接著到 系統設定 → 鎖定畫面：把「啟用螢幕保護程式後要求輸入密碼」設為立即。
    「這樣不是沒密碼就能進來？」— 兩個一起設就不會：開機後它自動登入、背景服務照跑，但螢幕很快進入鎖定，碰機器的人一樣要輸入密碼。若機器放在人來人往的開放空間仍不放心，就不開自動登入 — 重開機後從 MacBook 用 5-2 連進登入畫面遠端輸入密碼即可。
    選項反灰的話：是「檔案保險箱 FileVault」開著（新機常預設開啟）。到 系統設定 → 隱私權與安全性 → 檔案保險箱 關閉它，再回來設定。固定放在辦公室的常駐機，拿磁碟加密換自動開機回復，是合理的取捨。
  3. 打開螢幕共享 — 系統設定 → 一般 → 共享：開啟「螢幕共享」。第 5 章遠端設定會用到，順手先開好。
第 2 章

iCloud 設定兩台 Mac 都做

這一章是整份指南最重要的設定，兩台 Mac 都要做：

  1. 系統設定 → 最上方你的名字 → iCloud：確認「iCloud 雲碟」是開啟的。
  2. 同一頁找到「最佳化 Mac 儲存空間」，把它關閉。
為什麼一定要關：開著的話，macOS 會把一陣子沒動的檔案從硬碟移走、只留一個雲端空殼。人用 Finder 點開它會重新下載，感覺不到差別；但 Claude Code 直接讀檔案時，讀到的就是空殼。工作資料夾必須完整留在硬碟上。
第 3 章

建立共用工作資料夾

工作資料夾用 Obsidian 管理 — 它是一款筆記 App，筆記存成一般的純文字檔，Claude Code 可以直接讀寫。Obsidian 把一個工作資料夾叫作 vault。從 iPhone 開始建，是讓三台裝置都看得到最省事的做法：

3-1 iPhone：建立 vault在 iPhone 做

  1. App Store 搜尋 Obsidian，安裝並打開。
  2. 點 Create new vault，取名（例如 workspace），把 Store in iCloud 打開，建立。

3-2 兩台 Mac：打開同一個 vault兩台 Mac 都做

  1. 到 obsidian.md 下載 Mac 版 Obsidian，拖進「應用程式」。
  2. 打開 Finder → 側邊欄 iCloud 雲碟 → 會看到 Obsidian 資料夾，裡面就是剛剛建立的 vault（等一兩分鐘同步）。
  3. 打開 Obsidian → Open folder as vault → 選那個資料夾。
  4. 在 Finder 對這個 vault 資料夾按右鍵 → 「保留已下載項目」。
    為什麼：這是對第 2 章的雙保險 — 明確告訴 macOS：這個資料夾永遠完整留在這台機器上，不准搬走。兩台 Mac 都要做。
第 4 章

安裝 Claude Code兩台 Mac 都做

4-1 安裝 VS Code

  1. 到 code.visualstudio.com/Download 下載 Mac 版，解壓縮後把 Visual Studio Code.app 拖進「應用程式」。
  2. 打開 VS Code → File → Open Folder → 選第 3 章的 vault 資料夾。

4-2 安裝 Claude Code

  1. 在 VS Code 按 Ctrl + `（ESC 下方那顆按鍵）打開終端機，貼上這行按 Enter：
    curl -fsSL https://claude.ai/install.sh | bash
  2. 裝完後執行這兩行，讓終端機認得 claude 這個指令（整段一起貼上）：
    echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc source ~/.zshrc
  3. 輸入 exit 關閉終端機，再按 Ctrl + ` 開一個新的，輸入：
    claude
  4. 第一次啟動會用英文問幾個設定：一路按 Enter 用預設值。跳出瀏覽器時，登入你的 Claude 帳號 — 每台 Mac 各登入一次，登同一個帳號。回到終端機後它會問「Do you trust the files in this folder?」，選 Yes。過程中 macOS 跳出的權限詢問一律按「允許」。
  5. 登入成功會看到 Claude Code 的對話介面。試著問它：「這個資料夾裡有什麼？」— 它答得出來就完成了。
第 5 章

遠端使用：人不在 Mac mini 旁邊的時候

檔案同步跨地點本來就會通，這一章解決的是：人不在 mini 旁邊，要用它。做法一律走 Tailscale — 不預設你們在同一個網路，辦公室、家裡、外面都是同一套連法。建議裝機那天就把 5-1、5-3 設好。

5-1 三台都裝 Tailscale

Tailscale 把你的裝置串成一個私人網路，在任何地方都像坐在 mini 旁邊 — 不用固定 IP、不用動公司網路設定，個人用途免費：

  1. 兩台 Mac 到 tailscale.com/download 下載安裝；iPhone 從 App Store 裝 Tailscale。三台登入同一個 Tailscale 帳號（用 Apple 或 Google 帳號註冊即可）。
  2. 選單列的 Tailscale 圖示 → 確認機器都在線上，記下 Mac mini 的機器名稱。

5-2 從 MacBook 操作 mini 的畫面

在任何地方：MacBook 的 Finder 按 Cmd + K，輸入 vnc://mini的機器名稱，登入 mini 的帳號密碼，就能直接操作它的桌面。

5-3 在手機上用 Claude Code — Remote Control

Claude Code 內建遠端接管：mini 上的 session 持續跑著，手機的 Claude App 接上的是同一個 session — 原生對話介面，看進度、下指令都行。Pro / Max 帳號直接可用；Team 帳號需要管理員先在 claude.ai 的管理設定（Claude Code → Remote Control）開啟這個功能。在 mini 上設定一次：

  1. 在 VS Code 終端機貼上這段，在桌面建立啟動檔（vault 取了別的名字，把 workspace 換掉）：
    cat > ~/Desktop/啟動遠端.command <<'EOF' #!/bin/zsh cd "$HOME/Library/Mobile Documents/iCloud~md~obsidian/Documents/workspace" claude remote-control --spawn=same-dir EOF chmod +x ~/Desktop/啟動遠端.command
  2. 系統設定 → 一般 → 登入項目：在「登入時開啟」按 ＋，加入桌面的 啟動遠端.command。之後 mini 每次開機自動跑起來。
  3. 點兩下桌面的 啟動遠端.command 先跑第一次，依畫面指示用手機的 Claude App 掃 QR code 完成配對。跑起來後，mini 桌面會一直開著一個終端機視窗，裡面顯示「Connected」— 那就是這個服務本人：縮小沒關係，不要關，關掉視窗手機就連不上了。
  4. 平常人在外面：手機開 Claude App → Code 分頁，就看到 mini 上的 session — 點進去接管，下指令、看它跑到哪。要處理不同的事，直接開新對話 — 每個對話是獨立的 session，內容不會混在一起。電腦瀏覽器開 claude.ai/code 也是同一批 session。
手機連不上的時候：mini 斷網超過 10 分鐘，這個常駐程式會自己退出、不會自動重啟。回到機器前點兩下桌面的啟動檔就好；人在外面，就用 MacBook 照 5-2 連進 mini 桌面去點，或重開 mini（開機會自動帶起來）。

5-4 選配：在 iPhone 上看 mini 的完整桌面 — Screens

純選配 — 遠端救援用 5-2 的 MacBook 就夠。這是給「手邊只有手機、又想看整個桌面」的情境：

  1. iPhone 裝 Screens 5（App Store 的遙控 App，付費，內建 Tailscale 整合 — Tailscale 在 5-1 已裝好）。新增連線選你的 Mac mini，帳號密碼填 mini 的登入帳密。
  2. 連上看到的就是 mini 的桌面，跟坐在機器前一樣。
第 6 章

iPhone 的日常角色

手機端在第 3 章已經設定完成。設定好 5-3 之後，iPhone 不只是「看」— 它跟兩台 Mac 一樣，是 Claude Code 的正式入口。平常這樣用：

情境怎麼做
查資料、看筆記打開 Obsidian App，內容跟 Mac 上完全同步
路上想到什麼直接在 Obsidian 記下來，回到 Mac 它已經在了
跟 Claude 純聊天、討論想法用 Claude App（App Store 另外下載）的一般對話 — 不會動到工作資料夾
要叫 Claude Code 做事（讀檔、改檔、跑任務）Claude App → Code 分頁，接上 mini 的 session — 手機就是完整的 Claude Code 入口，能做的事跟坐在 mini 前一樣（設定見 5-3）
大量打字、長時間編輯回 Mac 做 — 差別只在打字體驗，不在能力
第 7 章

三機協作規則

iCloud 同步很可靠，但它是「同步」不是「合併」。記住四條規則，就不會踩到任何坑：

1｜同一份檔案，同一時間只在一台機器上改

兩台同時改同一份檔案，iCloud 不會幫你合併，會生出一份「檔名 2」的副本。最自然的做法：進行中的工作固定在一台機器上做完 — 例如在辦公室都用 mini、外出用 MacBook 看和記。

2｜換機器前，等它同步完

剛改完就切到另一台，常會看到舊版。Finder 裡檔案旁邊的雲朵或進度圈消失，就是傳完了 — 通常幾秒到一兩分鐘。

3｜MacBook 闔上蓋子 = 停止上傳

在 MacBook 改完東西要出門，先讓它開著蓋子等一下，確認同步完成再闔上；不然那些改動會留在 MacBook 裡，mini 上看到的還是舊版。

4｜看到「檔名 2」不要直接刪

那是規則 1 沒守住時撞出來的副本，兩份內容不一樣。打開比對、把內容併成一份再刪另一份 — 或者直接請 Claude Code：「這兩份檔案幫我比對差異、合併成一份」。

5｜檔案刪錯了，救得回來

Mac 上刪掉的檔案先進垃圾桶，撈回來就好。連垃圾桶都清了，30 天內到 iCloud.com → 資料回復，還救得回來。
